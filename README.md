# Luma Studio Website

A modern, responsive creative-studio landing page built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Services, featured projects, studio introduction, and contact sections
- Subtle hover effects and smooth anchor scrolling
- No frameworks or build tools required

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the published website URL to appear in the Pages section.

Replace the demo studio name, sample projects, and `hello@lumastudio.example` with your own details before submitting if your instructor expects a personal topic.
